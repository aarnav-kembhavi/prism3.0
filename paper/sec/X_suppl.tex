\section{Per-section results on OmniDocBench v1.6}
\label{sec:suppl_sections}

\Cref{tab:suppl_type,tab:suppl_lang,tab:suppl_layout} give the full breakdown of PRISM's final (v20) OmniDocBench v1.6 run by document type, language and layout. Text and reading order are normalized edit distance (lower better); CDM and TEDS are $\times100$ (higher better). A dash indicates the category contains no scorable instances of that element (e.g.\ magazines and newspapers carry no annotated display formulas). These are the disaggregated numbers behind the composite in \cref{tab:v16}; they localize the residual gap to GPU systems to a small number of capacity-bound cells --- simplified-Chinese and note-page formula CDM, and three-column / newspaper table TEDS --- rather than a diffuse deficit.

\section{Reproducibility}
\label{sec:suppl_repro}

All PRISM numbers are produced by the public OmniDocBench harness at its default configuration (quick-match matcher; CDM compiled with TeX~Live~2026). Accuracy is always reported CPU-only; the GPU measurements in \cref{sec:efficiency} affect latency only and never the emitted text. The complete cumulative experiment log --- every configuration change with its measured effect, including all rejected directions --- accompanies the code release.
